# Exercice 3 (J1) — Mesurer l'effet du contexte

## Objectif

Constater par vous-même ce que change le contexte : la même question, posée dans un chat vide puis dans le Projet NOVA, et comparer les deux réponses point par point. L'exercice n'a pas de piège : il s'agit de regarder honnêtement ce qui change et ce qui ne change pas.

## Prérequis

Le Projet « NOVA — Spécifications » de l'exercice 2, avec ses instructions et ses quatre fichiers.

## La question

```text
Un client nous demande pourquoi il n'a pas eu de remise sur sa commande de 4 800 EUR HT alors qu'un collègue d'une autre société a eu 6 % sur une commande de 5 200 EUR. Que dois-je lui répondre ?
```

## Déroulé

1. **Chat vide.** Ouvrez une nouvelle conversation hors de tout Projet et envoyez la question telle quelle. Copiez la réponse dans un document de travail.
2. **Projet NOVA.** Ouvrez une nouvelle conversation dans le Projet et envoyez exactement la même question. Copiez la réponse à côté de la première.
3. **Comparaison.** Remplissez ce tableau :

| Critère | Chat vide | Projet NOVA |
|---|---|---|
| La réponse donne-t-elle un taux ou un palier ? Lequel ? | | |
| Ce taux est-il exact selon la page « Règles de remise » ? | | |
| Cite-t-elle une source ? Laquelle ? | | |
| Combien d'hypothèses fait-elle sans le dire ? Lesquelles ? | | |
| Pose-t-elle des questions avant de répondre ? Lesquelles ? | | |
| Le ton est-il utilisable tel quel face au client ? | | |
| Longueur (nombre de lignes) | | |

4. **Troisième essai.** Dans le Projet, reformulez la question avec les cinq blocs (rôle, contexte, contrainte, format, source) et notez ce qui change encore par rapport à l'essai 2.

## Questions pour le binôme

- Le chat vide a-t-il donné une réponse fausse, ou une réponse vraie en général mais fausse pour NOVA ? Laquelle des deux est la plus dangereuse dans votre quotidien ?
- Le Projet a-t-il repéré que 4 800 EUR est sous le palier de 5 000 EUR, et que le client de l'autre société peut avoir une autre catégorie ? Sinon, qu'est-ce qui manquait à la question ?
- Combien de temps auriez-vous mis à retrouver la règle vous-même dans les pages de spécification ?

## Ce que vous rendez

Le tableau rempli et une phrase de conclusion personnelle : « dans mon travail, le contexte que je devrais donner et que je ne donne jamais, c'est… ».
